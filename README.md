# 🏦 Banco Sol - Banca Móvil

Proyecto de aplicación web de banca móvil desarrollado como parte del trabajo escolar.

## 📄 Archivos del proyecto
- **login.html** — Inicio de sesión y registro de cuentas
- **dashboard.html** — Panel principal con operaciones bancarias

## ✅ Funcionalidades
- Registro e inicio de sesión de usuarios
- Bienvenida personalizada con el nombre del usuario
- Visualización y ocultamiento de saldo
- Recarga telefónica
- Pago de servicios
- Transferencias
- Cobros y retiros
- Cerrar sesión

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript
- LocalStorage (almacenamiento de datos)
